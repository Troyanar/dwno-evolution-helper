Digimon World Next Order Evolution Helper
=========================================

A companion window for Digimon World: Next Order (Steam, Windows).

SETUP
1. Close the game.
2. Run DWNO-Evolution-Helper.exe.
   If "Windows protected your PC" appears: "More info" -> "Run anyway" (the EXE is not signed).
3. Click "Install" in the setup screen. This downloads the mod loader BepInEx (official build)
   into the game folder and adds the plugin.
4. Start the game (the first start takes 1-3 minutes longer) and load your save.
   The window now shows your partners live: which digivolutions are possible, what is missing and when.

TIPS
- Digidex: every Digimon with its requirements, pre-evolutions and evolutions - works without the game.
- Log: every digivolution with the values right before it.
- Hotkeys (also in game): Ctrl+Shift+E show/hide · Ctrl+Shift+D click-through (clicks go to the game).
- Language: English by default; change it in the setup screen (gear icon), "Auto" follows the game.
- The window can only stay on top of the game in windowed or borderless mode, not in exclusive fullscreen.

UNINSTALL
Gear icon -> "Remove plugin". To remove BepInEx completely, delete the BepInEx folder and
winhttp.dll in the game folder.
